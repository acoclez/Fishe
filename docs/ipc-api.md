# IPC API

Contract between the Svelte UI and the Rust backend. The Rust side is the
source of truth: the commands in `src-tauri/src/commands.rs` and the
`Serialize`/`Deserialize` types they use (`monitor/`, `archive/`, `route/`,
`lan/`, `geo/`, `mcp/`, `net/`, `process/`, `npcap.rs`, `error.rs`).

**The TypeScript side is generated**, not written: every command carries
`#[specta::specta]` and every IPC type derives `specta::Type`; the
`tauri_specta::Builder` in `src-tauri/src/lib.rs` lists the commands once
(it is also the `invoke_handler`) and exports `src/lib/api/bindings.ts`, which
holds a typed `commands.*` function per command and one TypeScript type per
Rust type. `src/lib/api/types.ts` re-exports those types (plus a few UI-only
ones) and `src/lib/api/index.ts` adapts `commands.*` into the `api` object the
components use (defaults, channel callbacks, the save dialog, `void`
results). `bindings.ts` is checked in and regenerated by `cargo test`
(the `bindings_are_current` test fails once when it was stale) and by every
`npm run tauri dev` start; see [development.md](development.md#ipc-bindings).

The tables and snippets below describe the same contract for reading; when
they and `bindings.ts` disagree, the generated file is right.

All payloads are **camelCase** JSON. Rates are **bytes per second**; the UI
converts to bits when that unit is selected.

## Errors

Every failing command rejects with:

```ts
interface AppError { code: string; message: string }
```

| `code` | Meaning |
|---|---|
| `npcap_unavailable` | Capture is not possible: Npcap not found (Windows), or no permission to capture (Linux) |
| `invalid_target` | Not an IP / resolvable host name, or an empty program name |
| `interface_not_found` | The requested device name doesn't exist |
| `no_route` | No usable interface (to the host, or none active in process mode) |
| `process_not_found` | Process mode by PID: no such process |
| `capture` | Npcap/libpcap error (open, filter, read) |
| `not_found` | No such recording |
| `invalid_argument` | Input out of range or not allowed (recording name length, a path outside the archive) |
| `invalid_state` | Right request, wrong moment: recording with no session running, deleting a recording still being written |
| `busy` | Limit reached or resource in use: a recording already running, five pings at once |
| `unavailable` | Not offered here: owner database not installed, process mode on a system other than Windows and Linux |
| `io` | File or network I/O failed; the message says what was being done |
| `internal` | Anything else (thread spawn, OS query failure, archive database) |

The UI shows `message` as-is; `code` is for branching (the MCP server passes
both through to agents).

### `StartRequest`

```ts
{
  target:
    | { kind: "host"; address: string }                 // "1.1.1.1", "example.com"
    | { kind: "process"; selector:
          | { by: "name"; name: string }                // all instances, incl. future ones
          | { by: "pid"; pid: number } }                // exactly one process
    | { kind: "all" };                                  // every packet, labelled by program
  interface?: string | null;      // null/"" = host: route's adapter, process: all active,
                                  //           all: all active network adapters (no loopback)
  gauge?: Partial<GaugeConfig>;   // overrides; missing fields = defaults
  tickMs?: number;                // 50..2000, default 250
  naming?: {                      // process and all modes, see endpoints.md
    sniff?: boolean;              // DNS + TLS server names from the wire (default true)
    reverseDns?: boolean;         // PTR lookups for unnamed endpoints (default true)
  };
}
```

## Events (`subscribe_monitor`)

One `Channel<MonitorEvent>` per window, set once with `subscribe_monitor`;
every session (started by a click or by an agent) reports through it.
Tagged by `kind`:

```ts
| { kind: "started"; session: SessionInfo }
| { kind: "sample"; ...Sample }
| { kind: "warning"; sessionId: number; message: string }      // e.g. one interface failed
| { kind: "recordingStarted"; sessionId: number; recording: RecordingInfo }
| { kind: "recordingStopped"; sessionId: number; recording: RecordingInfo }  // stopped, or the session ended while recording
| { kind: "stopped"; sessionId: number; reason: "userRequested" | "error"; message: string | null }
```

Order per session: `started` → (`sample` | `warning` | `recording…`)* →
`stopped`. The UI follows the session named by `started` and ignores events
carrying another `sessionId`, so a late sample from a stopped session never
pollutes the new one. Subscribing while a session runs gets its `started`
again (a reload picks the session back up).

### `Sample` (one per tick)

| Field | Type | Meaning |
|---|---|---|
| `sessionId` | number | |
| `tMs` | number | ms since capture start |
| `intervalMs` | number | real tick length used for rates |
| `inBps` / `outBps` | number | bytes/s in / out this tick (see direction below) |
| `inPps` / `outPps` | number | packets/s |
| `smoothedBps` | number | fast EWMA of total (drives the needle) |
| `baselineBps` | number | learned normal level |
| `ratio` | number | `smoothed / max(baseline, floor)` |
| `level` | `"idle" \| "calm" \| "busy" \| "spike"` | |
| `peakBps` | number | max total rate this session |
| `totals` | `{ bytesIn, bytesOut, packetsIn, packetsOut }` | cumulative |
| `transports` | `{ tcp, udp, icmp, other }` | cumulative bytes |
| `topPorts` | `{ transport, port, bytes, packets }[]` | up to 8, by bytes |
| `dropped` / `ifDropped` | number | pcap drop counters, summed over interfaces |
| `unattributed` | number | packets without an owner: process mode, never found (not counted); all mode, counted as *Unattributed* (incl. ICMP etc.) |
| `process` | `{ pids, pidCount, sockets, knownPorts } \| null` | process mode live state; all mode: machine-wide (`pids` empty, `pidCount` = PIDs owning sockets) |
| `endpoints` | `{ total, rows: EndpointRow[] } \| null` | process and all modes: remote endpoints (≤ 150 rows) |
| `programs` | `{ total, rows: ProgramRow[] } \| null` | all mode: programs, busiest first (≤ 100 rows) |
| `quality` | `QualityTick \| null` | TCP connection quality of the counted traffic |
| `recording` | `{ id, elapsedMs, samples, pcapPackets, pcapDropped } \| null` | while recording |

### `EndpointRow`

```ts
{
  ip: string;
  name: string | null;
  nameSource: "sni" | "dns" | "echOuter" | "reverseDns" | null;
  owner: Owner | null;                           // public addresses, see owners.md
  hops: number | null;                           // estimated from received TTLs, see network-map.md
  scope: "public" | "private" | "loopback" | "linkLocal" | "cgnat"
       | "multicast" | "broadcast" | "unspecified" | "documentation";
  inBps: number; outBps: number;                 // this tick
  smoothedBps: number; baselineBps: number; ratio: number; level: Level;  // own detector
  peakBps: number;
  totals: { bytesIn; bytesOut; packetsIn; packetsOut };
  topPorts: { transport; port; bytes }[];        // ≤ 4
  firstSeenMs: number; lastSeenMs: number;       // session time
  programs?: { key: string; name: string; bytes: number }[];  // all mode: ≤ 3, biggest first
  quality: EndpointQuality | null;               // null without TCP traffic
}
```

### Connection quality

See [connection-quality.md](connection-quality.md).

```ts
interface EndpointQuality {
  srttMs: number | null;          // smoothed TCP RTT (gain 1/8)
  minRttMs: number | null;
  jitterMs: number | null;        // RFC 3550: smoothed |difference| of consecutive samples
  rttSamples: number;
  retransOutPct: number | null;   // share of TCP payload sent that was retransmitted
  retransInPct: number | null;    // share of TCP payload received that was a retransmission
}
interface QualityTick {
  rttMs: number | null;           // mean of the samples in the last 10 s
  rttTickMs: number | null;       // mean of this tick's samples
  minRttMs: number | null; srttMs: number | null; jitterMs: number | null;  // all samples in order
  recentSamples: number;
  retransOutPct: number | null; retransInPct: number | null;               // last 10 s
  dataOut: number; dataIn: number; retransOut: number; retransIn: number;  // session totals, bytes
  rttSamples: number;
}
interface PingStatus {
  ip: string; running: boolean; startedAtMs: number; sent: number; received: number;
  lossPct: number | null;         // last 60 probes
  lastMs: number | null; avgMs: number | null; minMs: number | null; maxMs: number | null; jitterMs: number | null;
  history: (number | null)[];     // last 120 probes, oldest first, null = lost
  error: string | null;
}
```

### `ProgramRow` (all mode)

```ts
{
  key: string;                    // lower-case exe name, "pid:N" while unnamed, "" = unattributed
  name: string;                   // "chrome.exe", "PID 1234", "Unattributed"
  pids: number[];                 // PIDs seen (≤ 16)
  inBps; outBps; smoothedBps; baselineBps; ratio; level; peakBps;   // own detector
  totals: Counters;
  endpoints: number;              // distinct remote addresses
  firstSeenMs; lastSeenMs;
}
```

### `PacketBatch` / `PacketRow`

```ts
interface PacketBatch { rows: PacketRow[]; nextSeq: number; enabled: boolean }
interface PacketRow {
  seq: number;                    // increasing; pass the last one as `after`
  tsUs: number;                   // capture time, µs since the Unix epoch
  iface: number;                  // index into SessionInfo.interfaces
  dir: "in" | "out";
  src: string; dst: string; transport: Transport; srcPort: number | null; dstPort: number | null;
  len: number;                    // frame length on the wire
  ttl: number;
  pid: number | null; program: string | null;   // all mode
  remoteName: string | null;      // best known name of the remote side
}
```

See [all-traffic.md](all-traffic.md).

**Direction:** host mode, in = host → this machine, out = this machine → host.
Process mode, in = received by the process, out = sent by it. All mode, in =
received by this machine, out = sent by it.

### Recording types

```ts
interface RecordingInfo { id: number; name: string; startedAt: number /* unix ms */; pcapPath: string | null }
```


## Permissions

App commands are allowed by default in Tauri 2. Capabilities
(`src-tauri/capabilities/default.json`): `core:default` only. The export
*Save as* dialog is opened by the backend, so the window holds no dialog
or file permission. The CSP restricts the webview to its own origin (its
scripts, styles and SvelteKit's version file) and the IPC endpoint.
